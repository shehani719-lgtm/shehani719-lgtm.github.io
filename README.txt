# Kaveesha Shehani — Business Analytics Portfolio

This is a beginner-friendly, no-paid-tools portfolio website for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — dark navy / blue design and responsive layout
- `Kaveesha-CV.pdf` — add your CV PDF here (optional)

## Publish with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. On the repository page, choose **Add file → Upload files**.
4. Upload `index.html` and `style.css` from this folder. You can also upload your CV PDF.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Select branch `main` and folder `/ (root)`, then click **Save**.
9. Wait a few minutes and visit `https://YOUR-USERNAME.github.io`.

## Personalize before sharing
Open `index.html` and use Find (Ctrl+F) to update:
- `Kaveesha Shehani` and your degree/expected graduation details if needed
- `kaveesha.shehani@gmail.com` if you want a different contact email
- `https://www.linkedin.com/` to your actual LinkedIn profile URL
- Project names/descriptions so they accurately describe your own work
- Each `href="#"` project link to the actual project URL, or leave it until you have one
- Add your CV PDF to this folder and name it `Kaveesha-CV.pdf`

The hero dashboard illustration and project artwork are CSS-made placeholders, not screenshots of your actual work. Replace them with screenshots of your own dashboards when you're ready. Only publish information and datasets that you're allowed to share.

## Editing later
For text edits, open `index.html` on GitHub, click the pencil/edit icon, make changes, and commit. For visual changes, edit `style.css`.
